# ATTER TOGO — site vitrine

Fichiers :
- index.html : structure complète du site
- styles.css : compléments CSS
- app.js : menu mobile, navigation active, formulaire de démonstration

Le site reprend une logique institutionnelle proche de la structure observée sur UMECTO :
hero, présentation, chiffres d'impact, actions/services, actualités, équipe, appel à l'action et contact.

IMPORTANT :
- Le contenu ATTER TOGO est une proposition de maquette : remplacez les textes par les informations officielles de l'association.
- Les coordonnées de contact sont des placeholders.
- Les images du hero viennent d'Unsplash et nécessitent Internet.
- Tailwind est chargé par CDN dans index.html. Pour une version production, vous pouvez installer Tailwind localement et compiler un CSS optimisé.

Pour tester :
1. Ouvrir index.html dans un navigateur.
2. Pour le formulaire réel, connecter l'événement submit de app.js à votre backend/service d'email.
