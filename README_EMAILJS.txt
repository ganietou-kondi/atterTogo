CONFIGURATION EMAILJS

1. Ouvrir app.js.
2. Remplacer REMPLACE_PAR_TON_TEMPLATE_ID par le Template ID EmailJS.
3. La Public Key est déjà configurée dans index.html.
4. Le Service ID est déjà configuré dans app.js : service_nswz2jh.
5. Ouvrir index.html dans le navigateur.
6. Remplir le formulaire Contact et envoyer.

Important : index.html charge EmailJS AVANT app.js. Il ne faut pas ajouter un deuxième <script src="app.js"></script>.
